# COSMOS — 3D-мир Солнечной системы

COSMOS — интерактивный образовательный проект с локализованным веб-сайтом и Android-приложением на Capacitor. Репозиторий включает казахский, русский и английский интерфейсы, Three.js-сцены планет и материалы для разработки.

## Структура монорепозитория

- `android/` — Android Studio проект на Kotlin и Capacitor.
- `web/` — Next.js сайт (исходники будут размещены здесь в этапе реорганизации веб-приложения).
- `assets/` — общие исходные текстуры, логотипы и другие медиа, если они используются несколькими приложениями.
- `docs/architecture/` — описание архитектуры.
- `docs/android/` — инструкции по Android.
- `docs/web/` — веб-документация и журнал истории веб-сайта.
- `docs/assets/` — происхождение и организация медиаресурсов.
- `scripts/` — общие скрипты сборки и синхронизации.

Git-корнем является каталог `COSMOS/cosmos` в текущем рабочем пространстве. Внешний каталог `COSMOS/android` может быть локальной ссылкой Android Studio на `cosmos/android`; исходники остаются в одном репозитории.

## Сборка и запуск

Инструкции для приложений и требования к окружению:

- [Android: настройка и сборка](docs/android/ANDROID_SETUP.md)
- [Архитектура](docs/architecture/ARCHITECTURE.md)
- [История веб-сайта](docs/web/DEVELOPMENT_LOG.md)

Веб-приложение сохраняет Next.js App Router и обычную серверную сборку. Android использует отдельный статический веб-пакет через Capacitor; сервер Next.js внутри Android не запускается.
