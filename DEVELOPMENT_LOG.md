# COSMOS — журнал разработки

## Этап 1 — подготовка проекта (14 ноября 2026)
- Проверено окружение: Node.js 24.21.0, npm 11.19.0, Git 2.56.0.
- Создан проект Next.js 16 с App Router, React 19, строгим TypeScript и Tailwind CSS 4.
- Подготовлены каталоги для 3D-сцены, данных, состояния, интерфейса и ресурсов.
- Добавлена начальная русскоязычная страница COSMOS.
- Совместимость: React Three Fiber 9 соответствует React 19; ветка 10 в официальной документации пока alpha.

### Осталось
- Реализовать дизайн-систему, интерактивную 3D-сцену, маршруты планет, научные данные и режим путешествия.

### Проверка этапа 1
- `npm run lint` — успешно.
- `npm run build` — успешно, включая проверку TypeScript.
- `npm run dev` — запущен на http://localhost:3000; HTTP 200.
- Исправлена ошибка типизации в сгенерированном `layout.tsx`.
- `npm audit` сообщает о 7 умеренных уязвимостях в дереве зависимостей; до релиза требуется разбор.

## Этап 2 — дизайн-система (14 ноября 2026)
- Добавлены CSS-переменные палитры, адаптивная навигация и переиспользуемая кнопка-ссылка.
- Начальная страница использует единый визуальный язык и видимый фокус клавиатуры.
- Проверки: ESLint, TypeScript, production build — успешно.
- Следующий этап: 3D-Земля в hero, звёздное окружение и переход к Солнечной системе.

## Этап 3 — в работе (14 ноября 2026)
- Добавлена настоящая WebGL-сцена: вращающаяся сфера Земли с картой NASA Blue Marble, освещением, атмосферным слоем, звёздами и лёгким движением камеры.
- Сцена загружается динамически. При отсутствии WebGL выводится текстовый fallback.
- Проверки: ESLint, TypeScript и production build — успешно. Ошибки правил React Hooks устранены.
- Осталось: переход управляемой камерой к Солнечной системе, кнопка начала исследования, визуальная проверка в браузере.
