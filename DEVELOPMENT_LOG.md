# COSMOS — журнал разработки

## Этап 1 — подготовка проекта (14 ноября 2026)
- Проверено окружение: Node.js 24.21.0, npm 11.19.0, Git 2.56.0.
- Создан проект Next.js 16 с App Router, React 19, строгим TypeScript и Tailwind CSS 4.
- Подготовлены каталоги для 3D-сцены, данных, состояния, интерфейса и ресурсов.
- Добавлена начальная русскоязычная страница COSMOS.
- Совместимость: React Three Fiber 9 соответствует React 19; ветка 10 в официальной документации пока alpha.

### Осталось
- Реализовать дизайн-систему, интерактивную 3D-сцену, маршруты планет, научные данные и режим путешествия.

### Проверка этапа 1
- `npm run lint` — успешно.
- `npm run build` — успешно, включая проверку TypeScript.
- `npm run dev` — запущен на http://localhost:3000; HTTP 200.
- Исправлена ошибка типизации в сгенерированном `layout.tsx`.
- `npm audit` сообщает о 7 умеренных уязвимостях в дереве зависимостей; до релиза требуется разбор.

## Этап 2 — дизайн-система (14 ноября 2026)
- Добавлены CSS-переменные палитры, адаптивная навигация и переиспользуемая кнопка-ссылка.
- Начальная страница использует единый визуальный язык и видимый фокус клавиатуры.
- Проверки: ESLint, TypeScript, production build — успешно.
- Следующий этап: 3D-Земля в hero, звёздное окружение и переход к Солнечной системе.

## Этап 3 — в работе (14 ноября 2026)
- Добавлена настоящая WebGL-сцена: вращающаяся сфера Земли с картой NASA Blue Marble, освещением, атмосферным слоем, звёздами и лёгким движением камеры.
- Сцена загружается динамически. При отсутствии WebGL выводится текстовый fallback.
- Проверки: ESLint, TypeScript и production build — успешно. Ошибки правил React Hooks устранены.
- Осталось: переход управляемой камерой к Солнечной системе, кнопка начала исследования, визуальная проверка в браузере.

### Ресурс
- NASA/Goddard Space Flight Center Scientific Visualization Studio, Blue Marble: https://svs.gsfc.nasa.gov/2915/ ; файл `public/textures/earth-blue-marble.png`.
- Условия использования NASA: https://www.nasa.gov/nasa-brand-center/images-and-media/

### Завершение этапа 3
- Добавлены кнопки «Начать исследование» и «О проекте». Первая запускает GSAP-перелёт камеры в том же WebGL Canvas к обзорной модели Солнечной системы; возврат тоже анимирован.
- Добавлены анимация появления текста, OrbitControls после перелёта, поддержка `prefers-reduced-motion` и предварительная загрузка карты Земли.
- Обзорная модель пока использует условные материалы и размеры; её детализация относится к этапу 4.
- В браузере проверены первый экран, перелёт, возврат, мобильная компоновка и отсутствие ошибок консоли. Исправлены слишком тёмная Земля и обрезанные орбиты.
- Следующий этап: полноценные планеты с проверенными текстурами, спутник Земли, свет и орбиты.

## Этап 4 — Солнечная система (14 ноября 2026)
- Цветная обзорная заготовка заменена модульной 3D-сценой с Солнцем и восемью текстурированными планетами.
- Добавлены собственное вращение, орбитальное движение, адаптированные размеры и расстояния, кольца Сатурна, осевой наклон Урана, свечение Земли, Луна, звёздное окружение и орбитальные линии.
- Планетные карты Solar System Scope распространяются по CC BY 4.0; карта Земли — NASA SVS. Источники указаны в README.
- Параметры движения и масштабы художественно адаптированы. Это не астрономическая симуляция.
- В браузере проверены карта всех объектов и отсутствие ошибок WebGL; ESLint, TypeScript и production build прошли.
- Следующий этап: выбор планеты, наведение, движение камеры к объекту и информационные карточки.

## Этап 5 — выбор планет и камера (14 ноября 2026)
- Добавлено состояние выбранной планеты в Zustand и доступная клавиатуре панель выбора восьми планет.
- 3D-сферы реагируют на наведение и клик; выбор открывает карточку с кратким фактом и ссылкой на NASA.
- Камера плавно отлетает от текущей планеты, затем приближается к следующей. Во время фокуса выбранная планета удерживается в кадре; доступны предыдущая, следующая и общий вид.
- В браузере проверены выбор Земли, переход к Марсу, возврат к общему виду и отсутствие ошибок консоли.
- Краткие факты сверены со страницами NASA, ссылки хранятся в `src/data/solarObjects.ts`.
- Следующий этап: отдельные страницы планет с проверенными числовыми характеристиками и датой актуальности меняющихся данных.
